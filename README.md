# 求职与职业发展技能库

> AI Agent Skills for Career Development —— 面试、简历、LinkedIn、成就表达

## 定位

为独立开发者和技术人员提供一套求职全流程 AI 技能，覆盖面试准备、简历优化、LinkedIn 建设和个人品牌包装。

## 核心理念

> 好工作不只是投出来的，更是准备出来的。让 AI 帮你发现盲点、优化表达、提升通过率。

- **面试练到不怕** — 一次一问 + 深度追问，直到你能自信回答任何问题
- **简历不卡 ATS** — 75% 的简历死在自动筛选，你的不应该
- **被人找到** — LinkedIn 不是存档工具，是让猎头找到你的搜索引擎
- **每句话都是成就** — STAR + X-Y-Z 公式，用数据证明你做了事
